Dry Eye Analysis Project 👁️📊
This project focuses on analyzing dry eye-related data to identify patterns, trends, and factors associated with dry eye symptoms. The project demonstrates data cleaning, exploratory data analysis, visualization, and insight generation using data analytics techniques.
Tools & Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn
Key Areas: Data Cleaning • Exploratory Data Analysis • Data Visualization • Pattern Analysis • Insights
